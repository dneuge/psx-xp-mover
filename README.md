# PSX/XP Mover

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE.md)

This plugin for X-Plane offers a **very basic** injection of position/orientation from Aerowinx Precision Simulator 10
(PSX) to an X-Plane (XP) aircraft model, e.g. the default Boeing 747-400 from X-Plane 11.

This is by no means a proper "scenery generator". The main goal is to have some visuals to stay motivated while working
on virtual cockpit integration. If you want proper integration with X-Plane, an actual "scenery generator" should be
used instead.
